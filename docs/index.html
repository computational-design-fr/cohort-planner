Cohort Planner

Standalone visual reports produced by python -m dcop.cli solve … --html: week grid, per-session utilities and relaxation traces, participant heatmap, solver convergence.

  • cohort_week — hand-made 8-person week, a weekly series, one impossible pair that falls back to asynchronous work
  • cohort_small — nominal 5-person case
  • cohort_large — 34 people, 19 meetings
  • cohort_conflict — over-constrained cohort that exercises the relaxation ladder
  • cohort_graph.synced — real organizer availability pulled from Microsoft Graph
